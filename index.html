Online Search (SerpAPI)

SerpAPI blocks direct browser calls (CORS). Run the local proxy first:
python3 proxy_server.py --key YOUR_SERPAPI_KEY
Then open http://127.0.0.1:8080 (not file://). The API key stays on your machine inside the proxy.

AI Search (OpenRouter)

AI answers go through the same local proxy. Start proxy with your OpenRouter key:
python3 proxy_server.py --key SERP_KEY --openrouter OR_KEY

Privacy

Local index data stays inside this browser. When online search is enabled, your query and API key are sent to SerpAPI only. No analytics from this app.
